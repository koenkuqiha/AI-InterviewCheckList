# Java JVM 思维导图 · 使用说明

两份思维导图，一个页面切换查看。**零依赖、纯本地、离线可用**。

## 打开方式

直接双击 `index.html` 即可（推荐）。
如果浏览器对本地文件有限制，用本地服务打开：

```bash
cd jvm-mindmap
python -m http.server 8899
# 浏览器访问 http://127.0.0.1:8899/index.html
```

## 页面功能

| 功能 | 说明 |
|---|---|
| **点击节点** | 叶子节点 → 右侧面板显示完整答案；分支节点 → 展开/折叠子节点 |
| **滚轮** | 以鼠标位置为中心缩放 |
| **拖拽空白处** | 平移画布 |
| **展开全部** | 展开所有知识点（自动按宽度缩放，保证文字可读） |
| **折叠到模块** | 只保留一级模块，快速看清整体结构 |
| **仅看重点** | 只显示 ★★★ 必考内容（约占实际面试提问的 70%），冲刺阶段用 |
| **适应画布** | 自动缩放至全图可见 |
| **顶部页签** | 切换「面试题版」/「学习清单版」 |

## 重点标记规则

| 标记 | 含义 | 复习建议 |
|---|---|---|
| ★★★（红点 + 红条） | 必考，必须能完整背诵 | 反复背，直到能 90 秒讲完 |
| ★★（橙色条） | 高频，需理解原理并能举例 | 理解为主，能画图/举例 |
| ★（灰色条） | 延伸加分项 | 知道有这回事即可 |

## 两份导图的区别

**面试题版**（58 节点 / 2 万字）
七大模块，每题含可直接背诵的答案，采用「一句话结论 + 支撑点 + 加分项 + 项目话术」结构。
1. 内存管理 ｜ 2. 类加载机制 ｜ 3. 垃圾回收 GC ｜ 4. 并发与内存模型 ｜ 5. 排查工具与实战 ｜ 6. LeetCode 高频关联 ｜ 7. 加分延伸

**学习清单版**（47 节点 / 1.2 万字）
九个阶段，每阶段含「学习内容 + 动手任务 + 验收标准」，总时长约 13-15天。
阶段 3（GC）与阶段 4（并发）权重最高；阶段 5（排查）与阶段 7（项目包装）最拉��差距。

## 关于 LeetCode 的说明

LeetCode 主站**没有 JVM 专项题目**。但其Concurrency（并发）标签下的题目直接考JUC与 JMM，
是国内面试的常见形式，已单独整理为第六模块：

- **1114 按序打印** → CountDownLatch / Condition
- **1115 打印奇偶数** → wait/notify 或 Semaphore（注意 while 而非 if）
- **1116 打印零与奇偶数** → 多个 CountDownLatch 协作
- **1188 设计有限阻塞队列** → ReentrantLock + 两个 Condition
- **1117 建造区域** → 状态机 + 条件变量
- **1195 K 进制** → 位运算 + 互斥

以及与 JVM 机制强相关的算法高频题：**146 LRU**（延伸讲软引用缓存与 Redis 淘汰策略）、
**1/20/141**、**剑指03（原地置换）**、**剑指22（快慢指针）**。

优先级标注沿用 LeetCode 的分级思路：★★★ / ★★ / ★。
